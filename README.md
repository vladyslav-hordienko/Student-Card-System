# Student Card Management System

Java OOP project modelling students and linked student-card records with automatically maintained derived information.

## Features
- `Student` objects contain personal, course, ID, email, and card information.
- Student email addresses are generated automatically from names.
- Each student owns a linked `StudentCard` object.
- Updating a student's name automatically updates both the email and cardholder name.
- Student-card creation and expiry information is handled using `LocalDate`.
- Multiple students are managed through Java Lists.

## What I practised
Encapsulation, composition, object lifecycle, derived fields, synchronising related objects, getters/setters, `LocalDate`, and Java Collections.
